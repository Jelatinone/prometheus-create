## 1. Outcome and acceptance

**Objective:** the editor shows a reconstructed object as a mesh or an inferred splat under one shared transform. One Generate action makes 2–3 objects. A persistent timeline drives what PNG (and later video) exports.

**Visible flow:** given an object whose `SceneObject.splat` references an S1 splat asset, when the user switches the layer to Splat and moves, rotates and scales the object, then the splat moves exactly with the mesh. It survives undo, fork and save/reload. Switching back to Mesh shows the same pose.

**Edge cases:** a missing or invalid splat falls back to the mesh with a notice. Scrubbing or switching layers never calls a provider. A Generate batch with one failed child keeps the others and retries only that child, without resubmitting a job that has a provider request ID.

**Out of scope:** splat persistence and provider work (Track A), shared contract changes without Cody's approval, remote video streaming, physics.

**Cut/fallback:** per checkpoint record in PLAN §5.

Checkpoint acceptance gates are the `acceptance_gate` fields of CP-011 to CP-015 in PLAN §5. Seams S1 (splat asset form: 3DGS PLY already in the mesh's object-local space, so the editor applies **no** extra normalization), S2 (`outcome.splatAsset`), S3 (attach in `lib/editor/reconstruction.ts`) and S4 phase 1 (child jobs on the existing single-mask API) are defined in PLAN §1 "Current continuation v4".

**Approval reference:** Cody, 2026-11-15: "/implement-next-checkpoint … begin work on track-b … keep going". PLAN v4 CP-011, approved 2026-11-14 23:40.

#### Objective

Add a Spark-backed splat layer to the editor viewport. An object whose `SceneObject.splat` points at a valid splat asset can be switched between **Mesh** and **Splat**, under the same object group and transform. A missing or invalid splat falls back to the mesh with a notice. S3 attach is in `lib/editor/reconstruction.ts`.

#### Scope and exclusions

- **In:**
  - `@sparkjsdev/spark` (exact version; package files);
  - a PLY header check in `lib/scene/splat.ts` (pure, tested);
  - a splat child per object in `lib/scene/viewport.ts`;
  - per-object layer switch and "Attach splat (.ply)" in the inspector, which uploads the PLY as a private `splat` asset and sets `splat` with `enabled: true`;
  - S3 attach plus tests;
  - a synthetic 3DGS PLY fixture under `tests/editor`.
- **Out:**
  - Track A's provider splat (CP-007/CP-008);
  - transform/undo/fork evidence for both layers (CP-012);
  - batch Generate (CP-012);
  - the timeline (CP-013).

#### Inputs and baseline

- `production@5f197ec`, with the seams as listed above.

- A splat is valid only when `validForGeometryRevision === geometry.geometryRevision` and the bytes parse as a binary little-endian 3DGS PLY.
- The upload path takes `splat` assets of any MIME type up to 50 MB (`lib/server/storage.ts`).
