## 1. Outcome and acceptance

**Objective:** prove and build the two highest-risk inputs: real capture frames entering the common ingestion contract (CT-002), and a real masked photo becoming a validated mesh. **Visible flow:** given a project in `MemoryBackend` (the platform backend once merged), when a user uploads an owned chair photo, or a consenting test caller changes their FaceTime camera view, then a `SourceRegistration` and `IngestEnvelope` are produced that pass `npm run validate` and are accepted by `ingestion.ingest`; when a mask is chosen, a `ReconstructionJob` moves queued → submitted → succeeded with its `providerRequestId` stored, and the output GLB passes `inspectGlb` (`npm run validate -- glb`) with plausible dimensions. Edge cases: duplicate and out-of-order Chert frames (`DUPLICATE`, `outOfOrder`), stale preview frames (`STALE_FRAME`), provider timeout or missing GLB (job `failed` with an error, no half-created object). **Out of scope:** persistence and HTTP ingestion (platform lane), editor UI beyond the `components/capture` panel, return video (F-012). **Cut/fallback:** PLAN CP-001 — upload-only ingestion and a labeled fixture mesh; no FaceTime or reconstruction claim without a real run. Timebox per PLAN schedule: Chert 60 min, reconstruction 30 min.

Integration seams: the Python agent validates against `lib/contracts/json-schema/ingest-envelope.schema.json`; envelopes go to the platform's `app/api/ingest` route once it exists. Masks align to the source's post-orientation pixel grid.

### Risks and rollback

- **Missing credentials:** with no `FAL_KEY`, owned photo, or Chert line, the live proofs cannot run. The adapters and error-path tests still land; the live rows stay `not_run`/blocked and Cody is asked for access. No fabricated success.
- **fal output conventions are undocumented** (units, up axis, whether transforms are baked, mesh scale may be normalized rather than metric). The normalizer records `sourceUnits`/`sourceUpAxis` as `unknown` unless the real file supports a claim. Dimensions stay `estimated` for user confirmation.
- **Status URL subpath ambiguity:** use `@fal-ai/client` (which builds URLs) and keep raw HTTP out of the adapter.
- **Paid duplicate jobs:** submit once, persist the request ID before polling, resume by request ID, and never auto-resubmit.
- **Chert on Windows:** the CLI does not support native Windows; use the managed outbound API, with the agent run in WSL or Linux. Capped at 60 minutes.
- **Browser-only code** (canvas, `getUserMedia`) cannot be unit-tested in the node test environment. It is kept thin, checked by hand, and the pure logic is tested separately.
- Rollback: everything is additive in lane-owned paths plus new dependencies; revert the branch commits. No shared file changes.
