## 1. Outcome and acceptance

**Objective:** generated objects come back from the provider with an inferred Gaussian splat stored in private storage. It sits in the same object-local space as the normalized mesh. The already-paid round-table result gets one without a new charge, and the 2–3 object path is grounded in real provider behaviour rather than its documentation.

**Visible flow:** given a succeeded `fal-ai/sam-3/3d-objects` result containing `model_glb` and `gaussian_splat`, when the runner finishes the job, it stores the raw GLB, the normalized mesh and a `splat` asset. That PLY's centres lie inside the normalized mesh bounds (within a recorded tolerance). The job output has `splatAssetId` and the outcome returned to the editor has `splatAsset`.

**Edge cases:** the splat is missing, malformed, over 50 MB after compaction, or has the wrong properties. In each case the job is a mesh-only success with a warning and `splatAsset: null`. A resumed job is never resubmitted.

**Out of scope:** editor rendering (Track B), shared contract changes without Cody's approval, room-wide or multiview fusion, new phone calls.

**Cut/fallback:** per checkpoint record in PLAN §5.

### CP-010 plan

Started 2026-11-15 after Gate M1 ("Ran smooth. Ending my test for now"; Cody then asked for the next checkpoint). Base: integrated `production@bb068d9` (this branch was fast-forwarded to it).

#### Objective
Every generated mesh above 100k triangles also gets a **cached simplified preview** (target 100,000 triangles) stored as its own private asset. The full-resolution normalized mesh stays the object's geometry and is never modified. The derivative is findable from the mesh it came from, so the editor can show it for interactive preview without recomputing. A visual comparison of original vs. derivative is recorded **before** the 100k figure is recommended as the default preview.

#### Scope and exclusions
- **In:**
  - `lib/reconstruction/mesh-simplify.ts`: a pure GLB simplifier on meshoptimizer `simplifyWithAttributes`. It keeps nodes, transforms (including the normalization root), materials and images. It rewrites only indexed triangle primitives whose attributes it understands (`POSITION`, `NORMAL`, `COLOR_0`, `TEXCOORD_0`). Any other layout returns "unsupported" and produces no derivative.
  - Runner: the finish stores the derivative best-effort (never fails the job), so `outcome.previewMeshAsset` / `previewNote` appear. A resumed succeeded job looks the derivative up and never recomputes it.
  - A no-cost `mesh_preview` route action, so existing objects such as the round table and the chairs can get a derivative.
  - Tests, README notes, the visual comparison.
- **Out:**
  - Editor display of the preview: Track B / CP-016. This note records how to consume it.
  - Any shared-contract change: `Geometry`, `Asset` and the job output stay as they are.
  - Making the derivative the object's geometry.
  - Texture downscaling, Draco/meshopt compression, collider generation.

#### Inputs and baseline
- **Benchmark:** HK-002 measured a 100k derivative of the round table offline: 1,047,216 → 100,000 triangles, 20.95 MB → 2.00 MB, 2.3 s, relative appearance error 3.9e-4.
